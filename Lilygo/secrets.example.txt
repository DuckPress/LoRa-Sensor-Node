# ================================================================
#  secrets.txt — NODE credentials, read from the SD card at boot.
#
#  Copy this file onto the root of the node's SD card as  /secrets.txt
#  and fill in your own values. It is NEVER compiled into the firmware,
#  so the published OTA binary contains no credentials.
#
#  Format: one "key=value" per line. Blank lines and lines starting
#  with '#' are ignored. The node reads this once per boot and caches
#  it in NVS, so you may remove the file after the first successful
#  boot if you'd rather not keep credentials on the card.
# ================================================================
